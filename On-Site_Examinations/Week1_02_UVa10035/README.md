# UVa 10035 - Primary Arithmetic

## 題目大意
輸入多組測資，每組有兩個不超過 10 位數的非負整數 `a` 跟 `b`，當輸入為 `0 0` 時結束程式。
題目要求計算這兩個數字在做直式加法時，總共會發生幾次「進位（carry）」，並依照進位次數輸出對應的句子。

## 解題想法
1. 用 `while (cin >> a >> b && (a != 0 || b != 0))` 持續讀取測資，遇到 `0 0` 就跳出。
2. 準備兩個變數：`carry = 0` 記錄目前有沒有進位、`count = 0` 記錄總共進位幾次。
3. 用 `while (a > 0 || b > 0)` 從個位數開始往左一位一位加：
   - 取出兩數的個位數 `a % 10` 跟 `b % 10`，再加上前一位來的 `carry`。
   - 如果總和 `>= 10`，代表有進位，就把 `carry` 設為 `1`，並讓 `count++`；否則 `carry` 設為 `0`。
   - 把 `a` 跟 `b` 都 `/= 10`，繼續處理下一位。
4. 最後根據 `count` 的大小（0、1、大於 1）印出對應的格式。

## 注意事項 / 容易踩的坑
- **單複數格式**：這題最容易 WA 的地方就是英文單複數跟句點：
  - 0 次：`No carry operation.`
  - 1 次：`1 carry operation.`（沒有 s）
  - 2 次以上：`X carry operations.`（有 s）
- **迴圈條件要用 `||`**：不能寫成 `a > 0 && b > 0`，因為兩個數字位數可能不一樣（例如 `999` + `1`），就算短的數字已經變 0 了，長的數字還是可能因為前一位的進位繼續連鎖進位。
- **資料型態**：題目說不超過 10 位數，用 `unsigned int` 或 `long long` 存比較不會爆掉。
