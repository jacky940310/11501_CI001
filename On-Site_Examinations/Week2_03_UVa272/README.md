# UVa 272 - TEX Quotes

## 題目大意
輸入一段包含多行的英文文章（讀到 EOF 為止），文章裡會出現普通的雙引號 `"`。
題目要求把所有雙引號成對轉換成 TeX 的引號格式：
- 遇到的第 1、3、5... 個（左引號）換成兩個反引號 `` `` ``
- 遇到的第 2、4、6... 個（右引號）換成兩個單引號 `''`
- 其他所有字元（包含空白和換行）都原封不動輸出。

## 解題想法
1. 宣告一個布林變數 `bool isLeft = true;`（或用計數器）來記錄下一個遇到的 `"` 應該是左引號還是右引號。
2. 用 `while (cin.get(c))` 一個字元一個字元讀取（或用 `getline` 逐行讀），直到 EOF。
3. 判斷讀到的字元：
   - 如果是 `"`：看 `isLeft` 的狀態，為 `true` 就輸出 `` `` ``，為 `false` 就輸出 `''`，然後把 `isLeft` 反轉（`isLeft = !isLeft;`）。
   - 如果不是 `"`：直接原樣輸出。

## 注意事項 / 容易踩的坑
- **不能用 `cin >>`**：這題必須保留原本所有的空白跟換行，用 `cin >>` 會把空白吃掉導致格式錯誤，要用 `cin.get()` 或 `getline()`。
- **狀態變數要放迴圈外面**：引號可能會跨行（這行開頭、下一行才結束），所以 `isLeft` 一定要宣告在 `while` 迴圈外面，不能每讀一行就重置。
- **引號字元別打錯**：左引號是兩個反引號 `` `` ``（鍵盤左上角 `Esc` 下面那個鍵），右引號是兩個單引號 `''`，不要誤打成一個雙引號 `"`。
