# UVa 490 - Rotating Sentences

## 題目大意
輸入多行文字（最多 100 行，每行最多 100 個字元，讀到 EOF 為止）。
題目要求把整段文字「順時針旋轉 90 度」後輸出，也就是原本的第 1 行會變成最右邊那一直排，最後一行會變成最左邊那一直排。

## 解題想法
1. 用陣列或 `vector<string>` 把所有輸入的句子存起來，用 `while (getline(cin, s))` 一行一行讀，同時記錄所有句子裡最長的長度 `max_len`。
2. 讀完之後用雙層迴圈來模擬旋轉後的輸出：
   - 外層迴圈 `j` 從 `0` 跑到 `max_len - 1`（代表現在要印原本每句的第 `j` 個字）。
   - 內層迴圈 `i` 從最後一行（`n - 1`）倒著跑回第 0 行（因為順時針轉 90 度，最後一行會在最左邊）。
3. 印字的時候判斷 `j` 有沒有超過這一行本身的長度：
   - 如果 `j < lines[i].size()`，就印出 `lines[i][j]`。
   - 如果超過了（代表這行比較短），就補印一個空白 `' '`。
4. 每跑完一次外層迴圈就換行。

## 注意事項 / 容易踩的坑
- **短行要補空白**：如果某一行比較短，千萬不能直接 `continue` 跳過，一定要印空白 `' '` 佔位，不然右邊（原本比較前面）的字會全部往左擠導致格式錯掉。
- **用 `getline` 讀取**：句子裡包含空白字元，不能用 `cin >>`。
- **迴圈方向別搞反**：順時針旋轉是「從最後一行印到第一行」，如果從第 0 行開始印會變成轉置（左右顛倒）。
