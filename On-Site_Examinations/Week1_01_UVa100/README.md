# UVa 100 - The 3n + 1 problem

## 題目大意
輸入兩個正整數 `i` 跟 `j`（會有多筆測資，讀到 EOF 為止）。
對於 `i` 到 `j` 之間的每一個數字 `n`，重複做以下運算直到變成 1：
- 奇數：`n = 3 * n + 1`
- 偶數：`n = n / 2`

計算過程中總共會經過幾個數字（包含一開始的 `n` 跟最後的 `1`），這個次數叫做 cycle length。最後要輸出原本的 `i`、`j`，還有這段區間內最大的 cycle length。

## 解題想法
1. 用 `while (cin >> i >> j)` 持續讀取測資直到結尾。
2. 因為題目沒保證 `i` 一定小於 `j`，所以先另外存區間的起點跟終點（`min(i, j)` 到 `max(i, j)`），原本的 `i` 跟 `j` 不動，方便最後直接輸出。
3. 寫一個迴圈把區間內的每個數字都跑過一遍，用 `while (n != 1)` 照題目規則去算它的長度（計數器從 1 開始）。
4. 每次算完就跟目前的 `max_len` 比較並更新，最後印出 `i j max_len`。

## 注意事項 / 容易踩的坑
- **輸出順序不能變**：如果測資給 `10 1`，輸出還是要印 `10 1`，不能因為前面比大小就把 `i` 跟 `j` 直接 swap 掉。
- **注意溢位**：雖然輸入範圍不大，但算 `3n + 1` 的過程中數字可能會突然飆高超過 `int` 上限，變數開 `long long` 比較保險。
